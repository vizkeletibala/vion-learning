# German Tutor Agent Skills

These task templates define how German Tutor supervises uploaded German B2 notes before webpage publishing.

Start with the shared normalization contract:

- `../german-b2-note-upload-publishing-guidelines.md`

Then create generated learner-facing objects with the section templates:

- `grammar-task-create`
- `vocab-task-create`
- `reading-task-create`
- `writing-task-create`
- `source-backed-upload-leftover-cleanup`

Important publishing rule: uploaded notes are source seeds, not final webpage copy. Every section must produce generated exercises/cards/prompts that remain source-backed and keep validation issues visible.
